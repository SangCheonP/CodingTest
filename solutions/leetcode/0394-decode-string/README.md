## 접근 방법

반복 횟수와 바깥 문자열을 각각 스택에 저장한다. 숫자는 여러 자리일 수 있으므로 기존 값에 10을 곱하고 현재 숫자를 더한다.

여는 대괄호를 만나면 반복 횟수와 현재 문자열을 저장하고, 새로운 StringBuilder로 안쪽 문자열을 처리한다. 닫는 대괄호에서는 저장한 횟수와 바깥 문자열을 꺼내 안쪽 문자열을 반복해서 추가하고 cur를 바깥 문자열로 되돌린다.

cur를 새 StringBuilder로 교체하므로 저장한 바깥 문자열과 안쪽 문자열이 서로 다른 객체다.

## 시간·공간복잡도

- N은 입력 길이, L은 최종 복원 문자열 길이, D는 최대 중첩 깊이.
- 정확한 시간 비용은 O(N + C). C는 모든 append에서 복사한 문자 수의 합이다. 마지막 toString의 O(L) 비용도 포함한다.
- 같은 문자가 중첩 단계마다 복사될 수 있으므로 이 구현을 항상 O(N + L)로 단정하지 않는다. 보수적 상한은 O(N + L × D)이며, 반복 횟수가 1인 깊은 중첩에서도 중간 문자열 복사가 발생한다.
- 추가 공간: O(N + L + D). 입력 문자 배열, 스택의 반복 횟수와 문자열, 현재 문자열, 반환 문자열을 포함한다.

## 힌트와 피드백

- 사용자가 풀이에 힌트를 사용했다고 명시했다. 힌트의 구체적 내용은 미기록이다.
- 마지막 오류는 닫는 대괄호 처리 부분이었으며 피드백으로 수정했다.
- 수정 전 코드가 없어 해당 오류가 단순 실수인지 상태 복원 개념 부족인지는 단정하지 않는다.
- 이 피드백을 봤다는 사실만으로 별도 개념 오류로 분류하지 않는다. 사용자가 별도로 명시한 풀이 힌트 사용에 따라 독립 구현 확인 대상으로 둔다.
