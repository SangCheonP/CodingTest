# 684. Redundant Connection

- 문제: https://leetcode.com/problems/redundant-connection/
- 난도: Medium
- 풀이 날짜: 2026-10-22

- 소요 시간: 30분 (사용자 확인)
- 결과: 독립 해결·힌트 미사용 (사용자 확인)
- 코드: [Solution.java](./Solution.java)

## 접근
Union-Find로 연결된 정점의 집합을 관리한다. 입력 순서대로 간선을 확인하며 서로 다른 집합이면 합친다. 이미 같은 집합에 속한 두 정점을 잇는 간선이면 순환을 완성하므로 해당 간선을 반환한다.

입력은 트리에 간선 하나를 추가한 형태이므로 순환은 하나다. 처음 합치기에 실패하는 간선은 그 순환에 속한 간선 중 입력에서 가장 뒤에 등장한 간선이며 문제의 반환 조건을 만족한다.

## 구현
- parent[i]는 부모 정점이며 초기에는 자신이 대표다. 정점 번호가 1부터 시작하므로 배열 길이를 n + 1로 둔다.
- find는 대표를 찾으며 경로 압축을 수행한다.
- merge는 find로 얻은 두 루트를 비교하고 rank가 낮은 루트를 높은 루트 아래에 붙인다.
- rank가 같으면 한쪽 루트 아래에 연결하고 새 대표의 rank를 1 증가시킨다. 경로 압축 후 rank가 실제 높이와 항상 같지는 않다.

## 수정 과정
사용자는 마지막 merge 구현에서 루트 xP, yP 대신 원소 x, y를 사용했다가 수정했다고 설명했다. 최종 코드에서는 루트끼리 비교·연결하고 루트의 rank를 사용한다.

사용자가 힌트 미사용을 명시했으며 해당 수정만으로 개념 부족이나 힌트 의존을 추정하지 않는다. 정답 공유 이후 제공된 설명도 최초 독립 해결 기록을 변경하지 않는다.

## 복잡도
n은 정점 수이자 입력 간선 수다.
- 시간: O(n α(n)), 경로 압축과 rank 기준 합치기의 분할 상환 분석
- 추가 공간: O(n), 배열 및 재귀 호출 공간 포함

## 검증
- [[1, 2], [1, 3], [2, 3]] → [2, 3]
- [[1, 2], [2, 3], [3, 4], [1, 4], [1, 5]] → [1, 4]
- 위 사례는 코드 흐름 검토이며 별도 로컬 실행은 수행하지 않았다. 채점 통과는 사용자 확인에 근거한다.
