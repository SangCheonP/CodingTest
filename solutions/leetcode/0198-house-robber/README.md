- 코드: [Solution.java](./Solution.java)

## 최초 접근과 개선
- 처음에는 DP 배열에 각 위치까지의 최대 금액을 저장해 해결했다.
- 현재 계산에는 직전 두 상태만 필요하므로 prev2, prev1 두 변수로 개선했다.
- 초기 배열 버전의 코드는 공유되지 않아 별도로 재구성하지 않았다.

## 최종 풀이
- prev1: 직전 집까지 고려한 최대 금액.
- prev2: 두 집 전까지 고려한 최대 금액.
- 현재 집을 건너뛰면 prev1, 선택하면 prev2 + num.
- 큰 값을 cur에 저장한 뒤 prev2, prev1 순서로 갱신한다.

## 복잡도
| 방식 | 시간 | 추가 공간 |
|---|---|---|
| DP 배열 | O(n) | O(n) |
| 두 변수 | O(n) | O(1) |

## 검토
- [1,2,3,1] → 4, [2,7,9,3,1] → 12.
- [0] → 0, [5] → 5, [2,1,1,2] → 4.
- 사용자 최종 로직을 유지하고 클래스·메서드 선언을 추가했다.
- 위 사례는 코드 흐름 검토다. 로컬 Java 컴파일·실행은 수행하지 않았다. 채점 통과는 사용자 확인에 근거한다.
