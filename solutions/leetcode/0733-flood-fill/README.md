# 733. Flood Fill

- 문제: https://leetcode.com/problems/flood-fill/
- 난도: Easy
- 풀이 날짜: 2026-10-18
- 채점 상태: 정답 (사용자 확인)
- 소요 시간: 20분 (사용자 확인)
- 최초 풀이: 독립 해결·힌트 미사용 (사용자 확인)
- 코드: [Solution.java](./Solution.java)

## 접근
시작점의 원래 색을 저장하고, 상하좌우로 연결된 같은 색의 칸을 DFS로 방문하여 색을 변경한다.

최초 풀이는 별도 visited 배열을 사용하여 사용자가 직접 작성했다. 풀이 후 개선 설명을 참고하여 색 변경을 방문 표시로 활용하는 버전을 저장했다. 최초 해결을 힌트 의존으로 분류하지 않는다.

## 개선 사항
- 방문한 칸은 원래 색과 달라지므로 별도 visited 배열 없이 중복 방문을 막는다.
- 원래 색과 변경할 색이 같으면 바로 반환한다. 변경할 내용이 없으며, 이 경우 색 변경으로 방문 여부를 구분할 수 없다.
- 범위와 원래 색 일치 여부를 재귀 함수 진입 시 확인한다.

## 복잡도
행 수 m, 열 수 n 기준:
- 시간: 최악 O(mn)
- 보조 공간: 재귀 호출 스택을 포함하여 최악 O(mn). 방문 배열은 제거했지만 전체 보조 공간이 O(1)이 되는 것은 아니다.

## 경계 조건
- 시작점 색과 변경 색이 같은 경우
- 한 칸짜리 이미지
- 대각선으로만 같은 색이 연결된 경우: 상하좌우 연결이 아니므로 변경하지 않음
- 직사각형 이미지

## 검증 및 복습
- 채점 정답은 사용자 확인에 근거한다. 별도 로컬 컴파일·실행은 수행하지 않았다.
- 풀이 후 개선 설명을 참고한 사실만으로 오답·힌트 의존 복습에 등록하지 않는다.
- 독립 재풀이 완료는 별도 확인 전까지 체크하지 않는다.
