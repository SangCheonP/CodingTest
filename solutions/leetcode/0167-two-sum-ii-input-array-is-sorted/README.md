# 167. Two Sum II - Input Array Is Sorted

- 문제: https://leetcode.com/problems/two-sum-ii-input-array-is-sorted/
- 난도: Medium
- 풀이 날짜: 2026-10-18
- 채점 상태: 정답 (사용자 확인)
- 소요 시간: 20분 (사용자 확인)
- 학습 과정: 최초 HashMap 풀이 정답 후, 투 포인터 접근과 이동 근거 설명을 참고하여 공간 제한을 만족하도록 개선
- 코드: [Solution.java](./Solution.java)

## 접근
정렬된 배열의 양 끝에 l, r을 둔다. 두 값의 합이 target이면 1부터 시작하는 위치를 반환한다. 합이 작으면 l을 증가시키고, 크면 r을 감소시킨다. 같은 원소를 두 번 사용하지 않도록 l < r인 동안 반복한다.

## 포인터 이동 근거
- 합이 작으면 현재 왼쪽 값에 후보 중 가장 큰 오른쪽 값을 더해도 부족하므로 해당 왼쪽 값은 제외할 수 있다.
- 합이 크면 현재 오른쪽 값에 후보 중 가장 작은 왼쪽 값을 더해도 크므로 해당 오른쪽 값은 제외할 수 있다.
- 이미 제외한 오른쪽 값은 이후 더 커진 왼쪽 값과도 목표 합을 만들 수 없어 r을 다시 증가시킬 필요가 없다.

## 복잡도
- 시간: O(n)
- 추가 공간: O(1)

## 학습 및 복습 기록
- 최초 HashMap 풀이는 정답을 찾았지만 최악 O(n)의 추가 공간을 사용하여 문제의 O(1) 추가 공간 조건을 만족하지 못했다.
- 최종 투 포인터 풀이는 접근·코드 및 포인터 이동 근거 설명을 참고한 뒤 사용자가 작성하여 정답을 확인했다. 최종 방법의 독립 해결로 기록하지 않는다.
- 단순 오타가 아닌 공간복잡도 개선 학습으로 기록한다. 사용자의 새 문제 우선 요청에 따라 복습은 뒤로 미루며, 재풀이 날짜는 확정하지 않는다.
- 독립 재풀이 완료는 별도 확인 전까지 체크하지 않는다.

## 경계 조건 및 검증
- 원소가 두 개인 배열, 중복 값, 음수가 포함된 배열
- 반환 위치는 배열 인덱스에 1을 더한다.
- 채점 정답은 사용자 확인에 근거한다. 별도 로컬 컴파일·실행은 수행하지 않았다.
