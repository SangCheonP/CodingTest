## 재귀 DFS
빈 트리는 깊이 0을 반환한다. 왼쪽과 오른쪽 자식 트리의 깊이를 구한 뒤 큰 값에 현재 노드 1개를 더한다. 깊이는 루트에서 가장 먼 리프까지 경로의 노드 수다.

## 레벨별 BFS
루트를 큐에 넣고, 매 반복 시작 시 큐 크기를 저장한다. 그 개수만큼 노드를 꺼내 자식을 추가하면 한 레벨을 처리한 것이므로 deep을 한 번 증가시킨다. 새로 추가한 자식은 다음 반복에서 처리한다.

## 복잡도
n은 노드 수, h는 트리 높이, w는 최대 레벨 너비다.

| 방식 | 시간 | 추가 공간 |
|---|---|---|
| 재귀 DFS | O(n) | O(h), 호출 스택 |
| BFS | O(n) | O(w), 큐 |

한쪽으로 치우친 트리에서는 재귀 깊이가 커지고, 넓은 트리에서는 큐 사용량이 커진다. 두 방식 모두 최악 추가 공간은 O(n)이다.
