- 난도: Medium

- 소요 시간: 30분 (사용자 확인)
- 결과: 사용자가 풀이를 작성함. 힌트·해설 사용 여부 미기록.

## 접근 방법

구간을 시작점 기준으로 정렬한다. 현재 병합 중인 구간의 시작점과 끝점을 저장하고 다음 구간을 확인한다. 현재 끝점보다 다음 시작점이 크면 기존 구간을 결과에 저장하고 새 구간을 시작한다. 겹치면 두 끝점 중 큰 값으로 확장한다. 마지막 구간은 반복문 종료 후 저장한다.

끝점과 시작점이 같으면 겹치는 구간으로 처리한다. Integer.compare를 사용해 비교 함수의 뺄셈 오버플로를 피한다. 문제 조건상 구간이 최소 한 개 있으므로 첫 구간으로 초기화한다.

## 시간·공간복잡도

- 시간: O(N log N). 정렬 후 O(N) 순회한다.
- 추가 공간: O(N). 결과 목록과 배열, 정렬에 필요한 보조 공간을 포함한다.
- N은 구간 개수.
- Arrays.sort는 입력 배열의 구간 순서를 변경한다.

## 검토와 복습

- 사용자 채점 정답 및 30분 기록에 근거한다.
- 공유 텍스트의 list.add 괄호를 수정하고, 반복문 닫는 중괄호를 배치해 마지막 저장과 반환을 반복문 밖으로 옮겼다. import와 메서드 선언을 추가했다.
- 코드 흐름 검토: [[1,3],[2,6],[8,10],[15,18]] → [[1,6],[8,10],[15,18]], [[1,4],[4,5]] → [[1,5]], [[1,10],[2,3]] → [[1,10]], [[2,2]] → [[2,2]].
- 별도 로컬 컴파일·실행 검증은 수행하지 않았다.
- 공유 텍스트의 문법·배치 오류는 복사 과정의 단순 오류로 보고 오답 복습에 넣지 않는다. 개념 또는 해결 전략 부족은 확인되지 않았다.
- 독립 재풀이 완료는 별도 확인 전까지 체크하지 않는다.
