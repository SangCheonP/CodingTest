## 접근 방법

오름차순 배열에서 목표 값이 있을 수 있는 닫힌 구간 [left, right]를 유지한다. 중간 값이 목표 값보다 작으면 왼쪽 경계를 mid + 1로, 크면 오른쪽 경계를 mid - 1로 옮긴다. 같으면 인덱스를 반환하고 탐색 범위가 없어지면 -1을 반환한다.

left <= right로 원소가 하나 남았을 때도 검사한다. 중간 인덱스는 left + (right - left) / 2로 계산해 유효한 비음수 인덱스 범위에서 left + right의 덧셈 오버플로를 피한다.

## 시간·공간복잡도

- 시간: O(log N). 매 반복에서 탐색 범위가 약 절반으로 줄어든다.
- 추가 공간: O(1). 고정된 개수의 변수만 사용한다.
- N은 입력 배열 길이.
