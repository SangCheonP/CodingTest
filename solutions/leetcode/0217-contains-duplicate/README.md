## 접근 방법

배열을 순회하며 지금까지 확인한 값을 `HashSet`에 저장한다. 현재 값이 이미 집합에 있으면 중복이므로 즉시 `true`를 반환한다. 처음 나온 값이면 집합에 추가한다. 끝까지 중복이 없으면 `false`를 반환한다.

## 시간·공간복잡도

- 시간: 평균 O(N). HashSet의 조회와 삽입은 평균 O(1)이다.
- 공간: O(N). 모든 값이 다르면 N개를 저장한다.
- N의 의미: 배열 nums의 길이.

## 오답과 반례

- 원인 1: `contains`를 `constains`로 작성해 컴파일 오류가 발생하는 코드였다.
- 원인 2: 중복 발견 시 `false`, 중복이 없으면 `true`를 반환해 조건이 반대였다.
- 반례 (메서드 오타만 수정한 이전 코드 기준): `[1, 2, 3, 1]`은 기대 결과 `true` / 코드상 결과 `false`, `[1, 2, 3, 4]`는 기대 결과 `false` / 코드상 결과 `true`.
- 수정한 점: `set.contains(n)`으로 이름을 고치고, 중복 발견 시 `true`, 순회 종료 시 `false`를 반환하도록 수정했다.
- 검토: 중복 있음, 중복 없음, 원소 한 개인 경우를 코드 흐름으로 확인했다. 로컬 Java 실행 도구를 찾지 못해 컴파일·실행 검증은 수행하지 않았다.
