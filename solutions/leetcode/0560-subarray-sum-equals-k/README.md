# 560. Subarray Sum Equals K

## 접근과 풀이
처음에는 투 포인터 또는 슬라이딩 윈도우를 고려했다. 음수가 있을 때 구간 합의 변화 방향이 보장되지 않아, 합이 크면 왼쪽을 줄이고 작으면 오른쪽을 늘리는 방식이 성립하지 않는다는 점을 학습했다. 음수가 있다는 이유로 모든 슬라이딩 윈도우 기법이 불가능한 것은 아니다.

최종 풀이는 누적합과 이전 누적합별 등장 횟수를 저장하는 맵을 사용한다. 현재 누적합을 sum이라 할 때, 이전 누적합이 sum - k인 위치마다 현재 위치에서 끝나는 합 k의 구간이 하나씩 만들어진다.

- map.put(0, 1): 배열 시작 전 누적합 0을 한 번 포함한다.
- 등장 횟수를 저장해야 동일한 누적합이 여러 번 나오는 구간도 모두 셀 수 있다.
- 현재 누적합은 조회 후 저장한다. 먼저 저장하면 k가 0일 때 빈 구간이 포함될 수 있다.

## 복잡도
- 시간: 평균 O(n), 해시맵 연산 평균 O(1) 기준
- 추가 공간: O(n)

## 경계 사례와 검증
- [4, -1], k = 3 → 1. 첫 값 4가 크다고 제거하면 정답 구간을 놓친다.
- [0, 0], k = 0 → 3. 같은 누적합의 등장 횟수가 중요하다.
- [1], k = 1 → 1. 첫 원소부터 시작하는 구간도 센다.
- 채점 정답은 사용자 확인에 근거하며 위 사례는 코드 흐름 검토다. 별도 로컬 실행은 수행하지 않았다.
