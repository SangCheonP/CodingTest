# 34. Find First and Last Position of Element in Sorted Array

- 문제: https://leetcode.com/problems/find-first-and-last-position-of-element-in-sorted-array/
- 난도: Medium
- 풀이 날짜: 2026-10-27
- 채점 상태: 정답 (사용자 확인)
- 소요 시간: 30분
- 결과: 힌트 사용 (사용자 확인)
- 코드: [Solution.java](./Solution.java)

## 최초 접근과 개선
- 최초: 이분탐색 후 for문으로 범위 확인. 최악 시간 O(n).
- 힌트를 받고 첫 위치와 마지막 위치를 각각 이분탐색하도록 개선.
- 최초 버전 코드는 공유되지 않아 재구성하지 않았다.

## 최종 풀이
- 첫 탐색: 같은 값을 찾으면 후보를 저장하고 왼쪽 범위를 계속 확인.
- 첫 위치가 없으면 [-1, -1] 반환.
- 두 번째 탐색: 같은 값을 찾으면 후보를 저장하고 오른쪽 범위를 계속 확인.

## 복잡도
- 시간: O(log n)
- 추가 공간: O(1)

## 검토
- 빈 배열, 없는 값, 단일 원소, 모든 원소가 같은 경우의 경계 확인.
- 사용자 로직을 유지하고 클래스·메서드 선언 및 들여쓰기를 추가했다.
- 로컬 Java 컴파일·실행은 수행하지 않았다. 채점 통과는 사용자 확인에 근거한다.
