## 접근 방법

숫자를 HashSet에 넣어 중복을 제거한다. 집합의 각 숫자 n에 대해 n - 1이 없으면 연속 구간의 시작점으로 판단한다. 이때만 현재 숫자부터 1씩 증가시키며 집합에 존재하는 숫자의 개수를 세고 최댓값을 갱신한다.

cnt를 0으로 초기화하고 cur 자체의 존재 여부를 검사하므로 시작 숫자도 길이에 포함된다. 빈 배열에서는 result의 초기값 0이 반환된다.

## 시간·공간복잡도

- N은 입력 배열의 원소 개수.
- 시간: 평균 O(N). 집합 생성과 순회에 O(N)이 들며 각 연속 구간은 시작점에서 한 번만 탐색한다. HashSet 조회는 평균 O(1) 기준이다.
- 추가 공간: O(N). 서로 다른 입력 숫자를 저장한다.
- 반복문이 중첩돼 있어도 각 구간의 숫자를 반복해서 세지 않으므로 O(N²)이 아니다.

## 막힌 부분과 사용한 힌트

- 처음에는 1부터 최댓값까지 숫자 존재 여부를 검사하면 O(N)이 될 것으로 생각했다.
- 숫자 범위 R과 입력 개수 N을 구분해야 한다. 최솟값부터 최댓값까지 검사하면 평균 O(N + R)이며 R = 최댓값 - 최솟값 + 1이다.
- 예: [1, 1000000000]은 입력 원소가 2개지만 범위를 훑으면 10억 번 검사하게 된다. 1부터 시작하면 음수도 놓친다.
- 사용한 힌트: 실제 집합 원소만 순회하고, 바로 앞 숫자가 없는 시작점에서만 연속 구간을 센다.
- 원인 분류: 시간복잡도 이해 및 중복 탐색을 줄이는 해결 전략. 단순 오타가 아니므로 개념 복습 대상으로 등록한다.
