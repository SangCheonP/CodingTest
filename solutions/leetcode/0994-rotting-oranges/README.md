# 994. Rotting Oranges

- 문제: https://leetcode.com/problems/rotting-oranges/
- 난도: Medium
- 풀이 날짜: 2026-10-20
- 채점 상태: 정답 (사용자 확인)
- 소요 시간: 20분 (사용자 확인)
- 결과: 독립 해결·힌트 미사용 (사용자 확인)
- 코드: [Solution.java](./Solution.java)

## 접근
신선한 오렌지 수 cnt를 세고, 처음 썩은 오렌지를 모두 큐에 넣는다. 매 단계 시작 시 큐 크기를 저장하고 그 개수만 처리하여 한 분 동안의 전파를 구현한다. 새로 썩은 오렌지는 큐에 넣을 때 바로 2로 변경하고 cnt를 감소시킨다. cnt가 0이면 경과 시간을 반환하고, 큐가 비었는데 신선한 오렌지가 남으면 -1을 반환한다.

## 공유 코드 수정
- DJ = {1, -1, 0, 0}을 {0, 0, 1, -1}로 수정했다.
- 방향 반복문 내부의 DI[0], DJ[0]을 DI[d], DJ[d]로 수정했다.
- 공유본 그대로는 대각선 한 방향만 반복 검사한다. 사용자 확인 정답 기록과 공유 텍스트의 오타를 구분한다.
- 기존 다중 시작점 BFS, 시간대 구분, 중복 방문 방지 접근은 유지했다. import와 클래스·메서드 선언 및 한국어 주석을 추가했다.

## 복잡도
행 수 m, 열 수 n 기준:
- 시간: O(mn). 초기 전체 순회 후 각 오렌지는 최대 한 번 큐에 들어가고 네 방향을 검사한다.
- 추가 공간: O(mn). 큐의 최대 크기.

## 경계 조건 및 검증
- 처음부터 신선한 오렌지가 없으면 0.
- 신선한 오렌지가 있지만 시작점이 없으면 -1.
- 빈칸으로 분리되어 도달하지 못하는 오렌지가 있으면 -1.
- 여러 시작점의 전파는 같은 시간대에 진행한다.
- 채점 정답은 사용자 확인에 근거한다. 저장한 오타 수정 버전의 별도 재제출 여부는 미확인이고, 로컬 컴파일·실행은 수행하지 않았다.

## 복습

- 해당 수정 피드백만으로 힌트 의존으로 분류하지 않는다.
- 독립 재풀이 완료는 별도 확인 전까지 체크하지 않는다.
