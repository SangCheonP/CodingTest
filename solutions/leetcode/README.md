# LeetCode 풀이

[학습 홈](../../README.md) · [96문제 문제집](../../docs/leetcode/problemset.md)

## 저장 규칙

문제 번호와 영문 이름을 조합한 폴더를 만듭니다. 순서 번호 대신 LC 번호를 사용하면 학습 순서를 바꿔도 경로가 유지됩니다.

| 파일 예시 | 역할 |
|---|---|
| `0001-two-sum/Solution.java` | LeetCode에 제출한 Java 코드 |
| `0001-two-sum/README.md` | 풀이 접근·복잡도·오답·재풀이 기록 |

폴더는 실제로 문제를 풀 때 만듭니다. 각 문제 폴더의 `README.md`는 [풀이 기록 양식](../../templates/solution-note.md)을 복사해 사용합니다. 코드에는 필요한 부분에 한국어 주석을 넣습니다.

## Java 파일 안내

LeetCode에서 제공하는 메서드 형태를 유지하고 `package` 선언은 넣지 않습니다. 파일마다 독립적인 `class Solution`을 사용하므로 여러 문제를 한꺼번에 컴파일하지 않습니다. `TreeNode` 같은 제공 타입을 쓰는 문제는 LeetCode 채점 환경이나 별도 로컬 테스트 환경에서 실행합니다.

풀이 코드는 작성 후 저장하고, 채점 상태는 문제별 노트에 기록합니다. 문제집의 최초 통과는 LeetCode 채점 통과 시 `✅`, 미통과·채점 미확인은 `☐`로 표시합니다. 독립 재풀이는 힌트·해설 없이 다시 풀어 채점 통과했을 때 별도로 체크합니다.

날짜는 `2026-10-02`, 소요 시간은 `20분` 형식을 사용합니다. 문제집에는 짧은 결과와 풀이 링크를 남기고, 접근 방법·복잡도·오답·반례는 문제별 `README.md`에 적습니다.

요약: `LC번호-문제이름/Solution.java`와 같은 폴더의 `README.md`로 풀이와 복기를 함께 관리합니다.
