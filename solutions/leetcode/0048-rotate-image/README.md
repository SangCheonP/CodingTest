- 소요 시간: 약 60분 (사용자 확인)
- 결과: 네 방향 교환 접근을 직접 작성. 반복문 증감·경계 수정과 마지막 모서리 중복 처리 설명을 참고한 뒤 정답.
- 사용 언어: Java

## 접근 방법

바깥층부터 안쪽층까지 네 위치의 값을 한 번에 교환한다. 상단의 값을 temp에 저장하고 상 <- 좌, 좌 <- 하, 하 <- 우, 우 <- 저장한 상 순서로 이동해 시계 방향 90도 회전을 수행한다.

i는 현재 층이다. j는 i부터 n - i - 2까지 증가한다. 네 모서리는 첫 교환에서 함께 처리되므로 한 변의 마지막 모서리는 다시 처리하지 않는다. 한 변 길이가 n - 2 * i이면 교환 횟수는 n - 2 * i - 1이다. 홀수 크기의 중앙 원소는 그대로 둔다.

## 시간·공간복잡도

- 시간: O(N²). 각 층의 원소를 교환한다.
- 추가 공간: O(1). 고정된 개수의 변수만 사용한다.
- N은 정사각형 행렬의 한 변 길이.

## 피드백과 복습 판단

- 최초 공유 코드의 j--를 j++로 수정했다.
- 경계를 j < n - i에서 j < n - i - 1로 수정하고, 마지막 모서리 중복 교환 이유를 설명했다.
- 사용자는 네 방향 교환 접근을 이미 직접 작성했다. 증감·인덱스 경계 수정 및 설명을 참고한 사실만으로 개념 오답 또는 힌트 의존 복습 대상으로 분류하지 않는다.
- 사용자 요청의 단순 실수 제외 기준에 따라 오답 복습에 등록하지 않는다. 해당 문제를 표본 복습이라는 이유로 재배정하지 않는다.
- 독립 재풀이 완료는 별도 확인 전까지 체크하지 않는다.
