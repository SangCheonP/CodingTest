# 200. Number of Islands

- 문제: https://leetcode.com/problems/number-of-islands/
- 난도: Medium
- 풀이 날짜: 2026-10-27
- 채점 상태: 원본 정답 (사용자 확인)
- 소요 시간: 약 20분
- 결과: 독립 해결·힌트 미사용 (사용자 확인)
- 코드: [Solution.java](./Solution.java)

## 풀이
- 전체 격자에서 아직 방문하지 않은 땅을 찾으면 섬 개수를 증가시킨다.
- DFS로 상하좌우에 연결된 땅을 방문하고 '2'로 표시한다.
- 방문 표시로 같은 섬을 중복 집계하지 않는다. 입력 격자를 변경한다.

## 코드 정리
- 원본은 dfs가 항상 1을 반환해 result에 더하는 방식으로 정답을 받았다.
- 풀이 후 제안에 따라 dfs 반환형을 void로 변경했다.
- 호출 직전에 result++로 섬을 집계하도록 변경했다. 탐색 로직은 동일하다.
- 풀이 후 코드 정리는 최초 풀이의 힌트 사용으로 분류하지 않는다.

## 복잡도
- 시간: O(행 × 열)
- 추가 공간: 최악 O(행 × 열), 재귀 호출 스택.

## 검토
- 원본 채점 통과는 사용자 확인에 근거한다.
- 수정본은 반환값과 집계 위치를 검토했다. 로컬 Java 컴파일·실행 및 온라인 재채점은 수행하지 않았다.
