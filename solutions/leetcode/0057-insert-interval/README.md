# LC 57 — Insert Interval

- 문제 링크: https://leetcode.com/problems/insert-interval/
- 문제집 학습 순서: 10
- 난도: Medium
- 풀이 날짜: 2026-10-13
- 채점 상태: 정답 (사용자 확인)
- 소요 시간: 약 30분 (사용자 확인)
- 결과: 처음 PQ를 이용해 풀이한 뒤 순회 방식으로 개선함. 힌트·해설 사용 여부 미기록.
- 사용 언어: Java
- 풀이 코드: [Solution.java](Solution.java)

## 접근 방법

입력이 시작점 순으로 정렬돼 있고 서로 겹치지 않는다는 조건을 활용한다. 새 구간 앞에 있는 구간을 저장하고, 새 구간과 겹치는 구간의 시작점과 끝점을 병합한다. 병합된 구간을 한 번 저장한 뒤 나머지 구간을 추가한다.

빈 입력에서는 새 구간만 저장된다. 결과의 각 구간을 새 배열로 생성하므로 입력 구간이나 newInterval을 변경하지 않는다.

## 시간·공간복잡도

- 시간: O(N). 세 반복문이 같은 인덱스 i를 이어서 증가시키므로 각 구간을 한 번 처리한다.
- 추가 공간: O(N). 반환할 구간 목록과 배열을 포함한다.
- N은 기존 구간 개수.
- 초기 PQ 풀이의 코드는 제공되지 않아 해당 구현의 복잡도와 정확성은 별도 판단하지 않는다.
