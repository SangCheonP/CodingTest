# 215. Kth Largest Element in an Array

## 접근
기본 PriorityQueue는 최소 힙이다. 원소를 하나씩 넣고 크기가 k를 초과하면 최솟값을 제거한다. 각 단계에서 지금까지 읽은 값 중 가장 큰 k개(원소가 k개 미만이면 전체)를 유지한다. 모든 원소를 처리한 뒤 peek()로 얻는 최솟값이 전체에서 k번째로 큰 값이다. 중복도 각각 저장되어 순위에 포함된다.

## 복잡도
- 시간: O(n log(k + 1)). 힙 크기는 일시적으로 최대 k + 1이다.
- 추가 공간: O(k).

## 경계 조건
- k = 1: 최댓값을 반환한다.
- k = nums.length: 최솟값을 반환한다.
- 중복 값도 별개 원소로 계산한다.
- 음수만 있는 배열에서도 동일하게 동작한다.
- 문제에서 1 <= k <= nums.length를 보장하므로 최종 peek()는 null이 아니다.
