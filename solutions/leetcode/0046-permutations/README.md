# 46. Permutations

- 문제: https://leetcode.com/problems/permutations/
- 난도: Medium
- 풀이 날짜: 2026-10-28
- 채점 상태: 원본 정답 (사용자 확인)
- 소요 시간: 약 30분
- 결과: 독립 해결·힌트 미사용 (사용자 확인)
- 코드: [Solution.java](./Solution.java)

## 풀이
- 방문하지 않은 원소를 선택하고 현재 목록에 추가한다.
- 재귀 호출 후 마지막 원소를 제거하고 방문 표시를 해제한다.
- 모든 원소를 선택하면 현재 목록을 복사해 결과에 저장한다.

## 코드 정리
- 원본은 바깥 for문에서 첫 원소를 선택한 뒤 재귀를 호출했다.
- 빈 목록으로 한 번 호출해 첫 원소 선택도 재귀 내부에서 처리하도록 정리했다.
- Intger를 Integer로 수정하고 import 및 클래스·메서드 선언을 추가했다.
- 풀이 후 정리와 철자 수정은 최초 독립 해결 기록을 변경하지 않는다.

## 복잡도
- 시간: O(n × n!), 결과 복사 포함.
- 추가 공간: 결과 제외 O(n), 결과 포함 O(n × n!).
