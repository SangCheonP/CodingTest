# 210. Course Schedule II

- 문제: https://leetcode.com/problems/course-schedule-ii/
- 난도: Medium
- 풀이 날짜: 2026-11-02
- 채점 상태: 정답 (사용자 확인)
- 소요 시간: 30분
- 결과: 독립 해결·힌트 미사용 (사용자 확인)
- 코드: [Solution.java](./Solution.java)

## 풀이
- 선수 과목에서 후속 과목으로 연결하고 진입 차수를 집계한다.
- 진입 차수가 0인 모든 과목을 큐에 넣는다.
- 과목을 처리하며 결과에 추가하고 후속 과목의 진입 차수를 줄인다.
- 처리한 과목이 전체보다 적으면 순환이 있으므로 빈 배열을 반환한다.
- 모든 과목을 처리하면 목록을 int 배열로 옮겨 반환한다.

## 복잡도
- V: 과목 수, E: 선수 조건 수.
- 시간: O(V + E).
- 추가 공간: O(V + E).

## 검토 및 복습
- infor를 info로, Queue<integer>를 Queue<Integer>로 수정했다.
- 사용자 로직을 유지하고 import 및 클래스·메서드 선언을 추가했다.
- 조건 없음·순환 조건·분리된 과목에서의 처리 흐름을 검토했다.
- 로컬 Java 컴파일·실행은 수행하지 않았다. 채점 정답은 사용자 확인에 근거한다.
- 단순 변수명·대소문자 오타는 복습에서 제외한다. 개념 부족이 확인되지 않아 오답 복습에 등록하지 않는다.
- 독립 재풀이 완료는 아직 확인되지 않았다.
