# 54. Spiral Matrix

- 문제: https://leetcode.com/problems/spiral-matrix/
- 난도: Medium
- 풀이 날짜: 2026-10-29
- 채점 상태: 정답 (사용자 확인)
- 소요 시간: 약 30분
- 결과: 독립 해결·힌트 미사용 (사용자 확인)
- 코드: [Solution.java](./Solution.java)

## 풀이
- 오른쪽·아래·왼쪽·위 순서로 이동한다.
- 범위 밖이거나 방문한 칸이면 시계 방향으로 전환한다.
- 방문 표시와 남은 칸 수로 중복 방문을 방지하고 종료한다.

## 복잡도
- 시간: O(n × m)
- 추가 공간: 결과 제외 O(n × m), 방문 배열.

## 검토 및 수정
- 공유 코드의 두 번째 di 선언을 dj로, isvalid 호출을 isValid로 수정했다.
- 사용자 로직을 유지하고 클래스·메서드 선언과 import를 추가했다.
- 한 칸·한 행·한 열 및 직사각형 입력의 이동·종료 흐름을 검토했다.
- 로컬 Java 컴파일·실행 및 수정본 온라인 재채점은 수행하지 않았다. 정답은 사용자 확인에 근거한다.

## 복습
- 변수명·대소문자 오타는 단순 실수로 복습에서 제외한다.
- 개념 부족이 확인되지 않아 오답 복습에 등록하지 않는다.
- 독립 재풀이 완료는 아직 확인되지 않았다.
