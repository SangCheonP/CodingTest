# 347. Top K Frequent Elements

- 문제: https://leetcode.com/problems/top-k-frequent-elements/
- 난도: Medium
- 풀이 날짜: 2026-10-28
- 소요 시간: 약 30분
- 최초 풀이: 힌트 미사용 (사용자 확인)
- 채점 상태: 사용자는 정답으로 보고했으나 공유 코드와 제출 코드의 일치 여부는 미확인.
- 저장 코드: 비교식 수정본. 온라인 재채점 미확인.
- 코드: [Solution.java](./Solution.java)

## 풀이
- 각 값의 등장 횟수를 집계한다.
- 빈도 오름차순 우선순위 큐에 값과 빈도를 저장한다.
- 크기가 k를 넘으면 가장 낮은 빈도의 원소를 제거한다.
- 남은 k개의 값을 반환한다. 결과 순서는 자유다.

## 수정 기록
- 공유 코드의 비교식은 빈도가 높은 원소부터 제거하는 방향이었다.
- Integer.compare(a[1], b[1])로 수정해 낮은 빈도부터 제거한다.
- 최초 힌트 미사용 보고와 풀이 후 비교식 수정 피드백을 구분한다.
- 비교식 수정만으로 개념 부족을 단정하거나 오답 복습에 등록하지 않는다.

## 복잡도
- n: 입력 길이, u: 서로 다른 값의 수.
- 시간: 평균 O(n + u log(k + 1)), 해시 연산 평균 O(1) 기준.
- 추가 공간: O(u + k).
- 이 방법의 최악 시간은 k가 클 때 O(n log n)이며, 추가 목표인 그보다 빠른 최악 시간까지 보장하지는 않는다.

## 검토
- [1,1,1,2,2,3], k=2에서 낮은 빈도를 제거해 1과 2가 남는 흐름을 확인했다.
- 로컬 Java 컴파일·실행 및 온라인 재채점은 수행하지 않았다.
- 독립 재풀이 완료는 아직 확인되지 않았다.
