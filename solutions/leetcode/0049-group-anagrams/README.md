## 접근 방법

각 문자열의 문자 배열을 정렬하고, 정렬 결과를 문자열로 변환해 Map의 키로 사용한다. 애너그램은 같은 문자와 같은 등장 횟수를 가지므로 정렬 결과가 같다.

`computeIfAbsent`는 키가 없을 때 새 목록을 생성하고, 이미 있으면 기존 목록을 반환한다. 이 목록에 원래 문자열을 추가한다. 마지막으로 Map의 값들을 목록으로 변환해 반환한다.

## 시간·공간복잡도

- 문자열 개수 N, 최대 길이 K 기준.
- 시간: 평균 O(N × K log K), 일반적인 문자열별 정렬 비용 기준. 문자열 복사와 키 해시 계산도 포함하면 O(N × (K log K + K)).
- 추가 공간: O(N × K + N). 서로 다른 정렬 키들과 각 그룹에 저장하는 원래 문자열 참조를 포함한다. 문자열 길이가 0인 경우에도 N개의 참조가 필요하다.
- 반환 결과를 포함한 분석이며, 원래 문자열 자체는 복사하지 않는다.

## 오답과 검토

- 공유한 코드에서 논리 오류는 발견하지 않았다.
- 빈 문자열은 빈 키로 묶이며 중복 단어도 목록에 각각 저장된다.
- `eat`, `tea`, `ate`는 모두 `aet` 키에 묶인다.
- 검토는 코드 흐름 확인이며 별도 로컬 컴파일·실행 검증은 수행하지 않았다. 채점 정답은 사용자 확인에 근거한다.
