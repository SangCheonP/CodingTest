# 78. Subsets

- 문제: https://leetcode.com/problems/subsets/
- 난도: Medium
- 풀이 날짜: 2026-10-19
- 채점 상태: 정답 (사용자 확인)
- 소요 시간: 30분 (사용자 확인)
- 결과: 사용자가 백트래킹 구조를 작성하고 인덱스 수정 피드백을 반영하여 정답
- 최초 접근의 힌트 사용 여부: 별도 미기록
- 코드: [Solution.java](./Solution.java)

## 접근
현재 부분집합 cur의 복사본을 결과에 추가한다. idx부터 각 후보 i를 선택하고, i + 1부터 재귀 탐색한다. 재귀 호출 후 마지막 원소를 제거하여 다음 후보를 탐색하기 전 상태로 복원한다. 최초 빈 리스트도 결과에 포함한다.

## 수정 사항
- idx는 현재 호출의 탐색 시작 위치이고 i는 반복문에서 실제 선택한 위치다.
- nums[idx]를 nums[i]로, 다음 재귀 시작 위치 idx + 1을 i + 1로 수정했다.
- 공유 코드에 빠져 있던 cur 선언과 클래스·메서드 및 import를 보완했다.
- 사용자가 이미 복사 저장, 선택, 재귀, 선택 취소의 구조를 작성했으므로 이번 인덱스 수정만으로 개념 부족이나 힌트 의존으로 분류하지 않는다.

## 복잡도
- n은 입력 원소 수.
- 시간: O(n × 2^n). 모든 부분집합을 생성하고 각 리스트를 복사한다.
- 반환 결과 공간: O(n × 2^n).
- 반환 결과를 제외한 보조 공간: O(n). 현재 부분집합과 재귀 호출 스택.

## 경계 조건 및 검증
- 원소 하나인 경우 빈 부분집합과 해당 원소만 있는 부분집합을 반환한다.
- 음수 및 0도 동일하게 처리한다.
- 결과 저장 시 복사본을 만들어 이후 cur 변경의 영향을 받지 않는다.
- 채점 정답은 사용자 확인에 근거한다. 별도 로컬 컴파일·실행은 수행하지 않았다.

## 복습
- 해결 방향이 맞는 상태의 일회성 인덱스 실수로 보아 복습에서 제외한다.
- 수정 설명을 참고했다는 사실만으로 힌트 의존 복습에 등록하지 않는다.
- 독립 재풀이 완료는 별도 확인 전까지 체크하지 않는다.
