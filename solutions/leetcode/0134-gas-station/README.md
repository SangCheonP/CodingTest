# 134. Gas Station

- 문제: https://leetcode.com/problems/gas-station/
- 난도: Medium
- 풀이 날짜: 2026-10-30
- 채점 상태: 정답 (사용자 확인)
- 소요 시간: 40분
- 결과: 힌트 사용 (사용자 확인)
- 코드: [Solution.java](./Solution.java)

## 직접 생각한 부분과 힌트
- 직접 생각한 부분: gas[i] - cost[i]로 각 지점의 연료 증감을 계산.
- 나머지 해결 전략은 힌트를 참고했다. 전체 연료 수지 확인과 출발 후보 갱신을 학습했다.

## 풀이
- total: 전체 경로의 연료 증감 합.
- tank: 현재 출발 후보부터 현재 지점까지의 연료 증감 합.
- tank가 음수가 되면 현재 출발 후보부터 현재 지점까지는 출발점이 될 수 없어 다음 지점으로 후보를 옮긴다.
- 이 구간의 이전 누적 연료가 음수가 아니었으므로 중간 지점에서 출발해도 현재 실패 지점까지의 연료는 부족하다.
- total이 음수면 불가능하므로 -1, 아니면 남은 출발 후보를 반환한다.

## 복잡도
- 시간: O(n).
- 추가 공간: O(1).
