## 접근 방법

dp[i]를 i칸까지 오르는 방법의 수로 정의한다. 마지막에 1칸을 올라왔다면 i - 1칸까지의 방법 수, 2칸을 올라왔다면 i - 2칸까지의 방법 수가 대응한다. 서로 겹치지 않는 두 경우를 합산한다.

dp[0] = 1은 아무 이동도 하지 않는 방법 한 가지를 의미한다. dp[1] = 1로 초기화하고 2부터 n까지 계산한다. 문제 조건은 1 <= n <= 45이므로 dp[1] 접근이 유효하다.

## 시간·공간복잡도

- 시간: O(N). 2부터 n까지 한 번 계산한다.
- 추가 공간: O(N). n + 1 크기의 배열을 사용한다.
- N은 계단 수 n.
- n = 45의 답 1,836,311,903은 int 범위 안이다.
