## 접근 방법

남은 문자를 Deque에 순서대로 저장한다. 현재 문자가 마지막 문자와 같으면 마지막 문자를 제거하고 현재 문자도 추가하지 않는다. 다르면 뒤에 추가한다. 마지막에 남은 문자들을 앞에서부터 StringBuilder에 담아 반환한다.

## 시간·공간복잡도

- 시간: O(N). 각 입력 문자를 한 번 처리하고 남은 문자로 결과를 만든다. LinkedList의 양 끝 조회·추가·제거는 O(1)이다.
- 추가 공간: O(N). 문자 배열, Deque, 결과 문자열을 포함한다.
- N은 입력 문자열 길이.
