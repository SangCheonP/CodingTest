# 102. Binary Tree Level Order Traversal

- 문제: https://leetcode.com/problems/binary-tree-level-order-traversal/
- 난도: Medium
- 풀이 날짜: 2026-10-29
- 채점 상태: 정답 (사용자 확인)
- 소요 시간: 30분
- 결과: 독립 해결·힌트 미사용 (사용자 확인)
- 코드: [Solution.java](./Solution.java)

## 풀이
- 빈 트리면 빈 결과를 반환한다.
- 큐에 루트를 넣고 각 반복 시작 시 현재 큐 크기를 저장한다.
- 저장한 개수만 처리해 같은 깊이의 값을 한 목록으로 묶는다.
- 왼쪽 자식, 오른쪽 자식 순서로 큐에 추가해 다음 깊이를 준비한다.

## 복잡도
- n: 노드 수, w: 트리 최대 너비.
- 시간: O(n).
- 추가 공간: 결과 제외 O(w), 결과 포함 O(n).

## 검토 및 복습
