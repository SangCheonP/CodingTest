- 문제 링크: https://leetcode.com/problems/valid-parentheses/
- 문제집 학습 순서: 7
- 난도: Easy
- 최초 풀이 날짜: 2026-10-08
- 채점 상태: 사용자 원본 풀이 정답 (사용자 확인). 정리한 코드의 재제출 결과는 미확인.
- 소요 시간: 20분 (사용자 확인)
- 결과: 사용자가 풀이 코드를 작성함. 최초 풀이의 힌트·해설 사용 여부는 미기록.
- 사용 언어: Java
- 풀이 코드: [Solution.java](Solution.java)

## 접근 방법

여는 괄호를 스택에 저장한다. 닫는 괄호를 만나면 스택이 비었는지 먼저 확인하고, 가장 최근의 여는 괄호를 꺼내 종류가 같은지 비교한다. 마지막에 스택이 비어 있어야 모든 괄호가 올바르게 닫힌 것이다.

사용자 요청에 따라 중첩 분기를 줄이고, peek 후 pop 대신 pop의 반환값을 사용하며, 마지막 반환을 isEmpty로 정리했다. 기존 해결 방향을 유지했다. 입력이 여섯 종류의 괄호로만 구성된다는 문제 조건에 따른 코드다.

## 시간·공간복잡도

- 시간: O(N). 문자열을 한 번 순회한다.
- 공간: O(N). 스택과 toCharArray의 문자 배열을 포함한다.
- N은 문자열 길이.
