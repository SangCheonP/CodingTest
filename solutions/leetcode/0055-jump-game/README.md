# 55. Jump Game

- 문제: https://leetcode.com/problems/jump-game/
- 난도: Medium
- 풀이 날짜: 2026-10-20
- 채점 상태: 정답 (사용자 확인)
- 소요 시간: 약 30분 (사용자 확인)
- 결과: 힌트 사용 후 그리디 방식으로 개선 (사용자 확인)
- 코드: [Solution.java](./Solution.java)

## 최초 접근
사용자 설명에 따르면 뒤쪽 인덱스부터 각 위치에서 1칸부터 최대 점프 거리까지 가능한 착지점을 확인하고, 마지막까지 갈 수 있는 위치가 있으면 true를 저장하는 방식이었다. 중간 가지치기도 사용했다. 도달 가능 여부를 저장하는 DP 접근으로 볼 수 있지만 이전 코드가 공유되지 않아 정확한 구현과 채점 결과는 확인하지 않았다.

## 개선한 접근
힌트를 참고하여 도달 가능한 가장 먼 인덱스 farthest만 유지하는 방식으로 수정했다.
- i > farthest이면 현재 위치에 도달할 수 없으므로 false를 반환한다.
- 도달 가능한 위치인 경우에만 i + nums[i]로 farthest를 갱신한다.
- farthest가 마지막 인덱스 이상이면 true를 반환한다.

최대 점프 거리 이하의 모든 거리를 선택할 수 있어 도달 가능한 범위를 연속 구간으로 관리할 수 있다. 반드시 도달 여부를 확인한 뒤 범위를 확장해야 한다. 반대로 하면 갈 수 없는 위치의 점프 거리를 사용하게 된다.

## 복잡도
- 현재 코드 시간: O(n).
- 현재 코드 추가 공간: O(1).
- 이전 설명처럼 위치마다 가능한 착지점을 모두 확인하는 방식은 최악 O(n²)이 될 수 있다. 구체적인 이전 코드가 없어 그 구현의 정확한 비용은 단정하지 않는다.

## 경계 조건 및 검증
- [0]: 시작점이 마지막 위치이므로 true.
- [0, 1]: 다음 위치로 갈 수 없어 false.
- [2, 0, 0]: 마지막 위치까지 도달할 수 있어 true.
- [3, 2, 1, 0, 4]: 막힌 구간을 넘을 수 없어 false.
- 위 항목은 코드 흐름 검토이며 별도 로컬 컴파일·실행은 수행하지 않았다.
- 채점 정답은 사용자 확인에 근거한다.
