# 238. Product of Array Except Self

- 문제: https://leetcode.com/problems/product-of-array-except-self/
- 난도: Medium
- 풀이 날짜: 2026-10-30
- 채점 상태: 정답 (사용자 확인)
- 소요 시간: 30분
- 결과: 힌트 사용 (사용자 확인)
- 코드: [Solution.java](./Solution.java)

## 풀이 및 힌트
- 사용한 힌트: 왼쪽 누적곱과 오른쪽 누적곱을 곱해 결과를 만든다.
- 첫 순회에서 result[i]에 자신보다 왼쪽 원소들의 곱을 저장한다.
- 역방향 순회에서 오른쪽 원소들의 곱 temp를 결합한다.
- result[i] 계산 후 temp에 nums[i]를 곱해 자기 자신을 제외한다.
- 빈 구간의 곱은 1로 시작한다. 나눗셈을 사용하지 않는다.

## 복잡도
- 시간: O(n).
- 추가 공간: 결과 배열 제외 O(1), 결과 포함 O(n).

## 검토 및 복습
- 사용자 로직을 유지하고 클래스·메서드 선언과 들여쓰기를 추가했다.
- [1,2,3,4], 0이 하나·둘인 경우의 계산 흐름을 검토했다.
- 로컬 Java 컴파일·실행은 수행하지 않았다. 정답은 사용자 확인에 근거한다.
- 핵심 접근에 힌트를 사용해 개념 복습 후보로 보존한다.
- 새 문제 우선 요청에 따라 재배정은 보류한다. 독립 재풀이 완료는 미확인이다.
