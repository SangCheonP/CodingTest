## 접근 방법

첫 번째 순회에서 `c - 'a'`를 이용해 영어 소문자를 0~25 인덱스로 변환하고, 길이 26의 배열에 등장 횟수를 저장한다.

두 번째 순회에서 원래 문자열을 앞부터 읽으며 등장 횟수가 1인 문자의 인덱스를 반환한다. 끝까지 없으면 -1을 반환한다. 원래 순서를 유지하므로 조건을 만족하는 첫 문자를 찾는다.

## 시간·공간복잡도

- 시간: O(N). 문자열을 두 번 순회한다.
- 추가 공간: O(1). 입력 길이와 관계없이 26칸 배열을 사용한다.
- N의 의미: 문자열 s의 길이.

## 오답과 검토

- 사용자가 설명한 접근에서 논리 오류는 발견하지 않았다.
- 영어 소문자만 입력된다는 문제 조건에서 `c - 'a'`를 사용할 수 있다.
- 검토 예시: `leetcode` → 0, `loveleetcode` → 2, `aabb` → -1, `a` → 0, `aabbc` → 4.
- 위 예시는 코드 흐름 검토이며 LeetCode 채점 통과를 의미하지 않는다.
